# AI Doc Assistant

Assistente inteligente para leitura, análise e extração de informações de documentos utilizando IA.

## Tecnologias
- Node.js
- Fastify
- PostgreSQL
- Docker
- JavaScript
- IA (Groq API)

## Funcionalidades
- Upload de documentos
- Leitura de PDF e DOCX
- Extração de texto
- Perguntas sobre arquivos
- Resumos automáticos
- API REST

## Como rodar

```bash
docker compose up -d
cd backend
npm install
npm run dev
